Dataset Kaggle

Dataset de maintenance prédictive des machines industrielles — capteurs mécaniques et thermiques, classifiant les types de pannes pour anticiper les défaillances.

📁 Machine Predictive Maintenance Classification

Données de capteurs industriels (température, vitesse, couple, usure outil) pour la classification des modes de défaillance et la prédiction de la maintenance.

📥 Ouvrir sur Kaggle

⚙️ Paramètres mécaniques

  • Vitesse de rotation : 1 200 – 2 000 rpm
  • Couple : 20 – 70 Nm
  • Température : 295 – 310 K
  • Rendement : 85 – 95 %

🌡️ Capteurs utilisés

  • Température air ambiant
  • Température process
  • Vitesse de rotation
  • Couple moteur
  • Tool wear (usure outil)

Bilan du Projet

Ce projet démontre une approche complète de maintenance conditionnelle basée sur les données capteurs. Avec une disponibilité de 93.62%, une accuracy de diagnostic de 92.4% et une prédiction RUL précise (R² = 0.94), le pipeline permet d'anticiper les pannes avant qu'elles surviennent — réduisant les coûts de maintenance et les arrêts non planifiés.
